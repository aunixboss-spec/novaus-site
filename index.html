Getting started

Up in three steps

Download and open a folder.

1

Download the installer

Grab the Windows .exe from GitHub Releases. macOS and Linux builds are on the roadmap.

2

Open a project

Point Novaus at any folder. The explorer, terminal and editor share the same workspace.

3

Write, run, ask the agent

Edit in Monaco, press F5 to run, or connect an API key and let the agent edit files and run commands.

AI Copilot

An agent that acts

Connect any OpenAI-compatible endpoint. The agent doesn’t only chat — it can read your project, write files and run terminal commands.

await agent.readFile("src/auth.ts")
await agent.editFile(path, changes)
await agent.run("npm test")

Decompiler

Built-in, offline

Most IDEs stop at source. Novaus can open common binary formats and show you readable output — without installing separate reverse-engineering tools for everyday formats.

.wasm
WebAssembly → WAT
.class
Java → javap / CFR
.pyc
Python bytecode
.dll / .exe
.NET → ILSpy
  • WABT tools for wasm are bundled — works offline
  • Useful for quick inspection, learning and debugging shipped artifacts
